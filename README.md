# hack-night

use by downloading folders, open chrome, go to chrome://extensions, turn on developer mode, click unload, then use the folder 


## Inspiration
We were spoiled from the Instagram reels of the demon slayer movie and got angry that we were spoiled.

## What it does
The extension blocks out posts/reels and lets us know that the post contains a certain keyword. We have the option to show it anyways.

## How we built it
We built it using Gemini and Claude, used HTML and CSS to make the visuals and used Javascript to program the logic.

## Challenges we ran into
Some challenges that we ran into were that Instagram would bug out and not function normally. As a result we had to get rid of a feature that wasn't a necessary component. Our algorithm also doesn't get every keyword depending on where it is and there are some reels or posts that make it ut as a result.

## Accomplishments that we're proud of
We were proud of making the extension work and learning how to use new technologies.

## What we learned
We learned how to use Gemini to speed up the coding process and work more efficiently.

## What's next for Instagram Content Filter
We will add more features like blocking profiles and improve our algorithm to be able to filter more.
